OCR Source Text Oncology — Biological Therapy
PROTOCOL: BIOLOGICAL THERAPY FOR ONCOLOGY Version 3.2 | Effective: 2024-01-01 Issuing Body: STMpha Clinical Advisory Board 1. SCOPE This protocol governs pre-authorisation decisions for biological and targeted therapy agents in oncology, including but not limited to: monoclonal antibodies, tyrosine kinase inhibitors (TKIs), immune checkpoint inhibitors, and CAR-T cell therapies. 2. ELIGIBILITY CRITERIA 2.1 MANDATORY (all must be met): a) Confirmed histological or cytological diagnosis of malignancy (ICD-O-3 code required) b) ECOG Performance Status 0–2 c) Adequate organ function: — Creatinine ≤ 1.5× ULN — ALT/AST ≤ 3× ULN (≤5× if hepatic mets) — ANC ≥ 1.0 × 10⁹/L — Platelets ≥ 75 × 10⁹/L d) Prior treatment failure or contraindication to standard first-line therapy (evidence required) e) Treating physician is a registered oncologist (HPCSA-registered, sub-specialty oncology) f) Treatment aligned to NCCN/ESMO guideline category 1 or 2A recommendation 2.2 CONDITIONAL (triggers Medical Advisor referral): a) ECOG Performance Status = 3 b) Organ function outside range but within protocol-defined exception thresholds c) Off-label indication (requires motivation letter) d) Prior biological therapy failure (>2 lines) 2.3 REJECTION CRITERIA (any one triggers rejection): a) ECOG Performance Status ≥ 4 b) No confirmed malignancy diagnosis c) Non-oncologist treating physician d) Experimental/trial-phase agent not on formulary e) Organ function critically outside threshold with no exception motivation provided 3. DOCUMENTATION REQUIRED — Histology/cytology report (within 12 months) — Recent bloods (within 30 days) — Oncologist treatment plan letter — Prior treatment history — Biomarker/genomic test results (where applicable) 4. VALIDITY PERIOD Authorisation valid for one treatment cycle (max 6 weeks). Renewal requires updated bloods.
